## 1. 频道房源主贴

### 图片

- 统一画布：1200×800，3:2。
- 默认：左大右二；有四张独立好图时使用左大右三。
- 首张是合成封面；Telegram 原生相册随后附真实照片。
- 图片下方不再放大黑框；价格和房源信息以白字轻阴影浮在主图上。

### 主贴文字模板

```text
🏠 项目/区域｜户型
💰 $租金/月

🏢 房产类型｜面积｜楼层
🔑 押付方式｜租期

🟢 当前可预约　QL-XX-XXXX

#区域 #户型 #租金区间
```

状态文案固定为：

- `🟢 当前可预约`
- `🟡 已有预约 · 仍可预约`
- `🔵 房态待确认`
- `🔴 已租出`
- `⚫ 已下架`

### 主贴按钮

可预约房源：

```text
🏠 房源详情    📅 预约看房
💬 中文顾问
```

不可预约房源：

```text
🏠 帮我找房    🔎 更多房源
💬 中文顾问
```

按钮行为：

- `🏠 房源详情`：打开 User Bot 的该房源详情/实拍入口。
- `📅 预约看房`：打开指定房源预约流程，不需要用户重新找房。
- `💬 中文顾问`：打开带该房源编号和基础信息的咨询入口。
- `🏠 帮我找房`：房源不可预约时进入找房流程。
- `🔎 更多房源`：查看同区域或当前可公开房源。

实拍页面文字结构：

```text

第 1/N 页 · 共 N 张

🏢 楼层
```

### 第一步：方式

文字：

```text
🏠 项目｜户型

没空到场？选择视频带看，顾问到现场实时带你看。

```

按钮：

```text
🚶 实地带看    🎥 视频带看
⬅️ 返回房源
```

### 第二步：日期与快捷时间

文字：

```text
🕐 选择看房时间

项目｜户型
已选：实地带看 / 视频带看

常用时段可直接选；没有合适时间再自己输入。
```

按钮按当天动态生成：

```text
今天下午 · M月D日（当天14点前才出现）
明天上午 · M月D日    明天下午 · M月D日
后天上午 · M月D日
其他日期 / 时间
⬅️ 返回上一步
```

### 第三步：自定义日期/时间

自定义日期：

```text
📅 输入日期

例如：
9月28日
0928
下周三
```

自定义时间：

```text
🕐 输入时间

例如：
20:00
晚上8点
```

时间按钮：

```text
上午 09:00–12:00
下午 14:00–17:00
其他时间
⬅️ 返回上一步
```

### 提交后

- 显示预约已记录。
- 明确说明“已记录不等于时间已确认”。
- 顾问需要确认最新房态和具体时间。

成功后的按钮：

```text

🔍 继续找房
```

## 8. Publisher 发布后台

后台首页：

```text

🔵 房态工作台     📡 采集状态
🕘 最近发布       ⚙️ 发布设置
```

### 手动发布房源

```text
➕ 发布房源
→ 输入/转发房源资料与照片
→ 系统解析事实
→ ➕ 补充资料 / ✏️ 修改资料
→ 💬 调整侨联说（可隐藏或恢复自动）
→ 👀 生成预览
→ 更换主图 / 重新生成 / 调整模板
→ 📤 确认发布到频道
→ 保存 Telegram receipt
→ 写入 publication_instances
```

资料确认按钮：

```text
➕ 补充资料    ✏️ 修改资料
💬 调整侨联说
👀 生成预览 / 📤 检查并发布
❌ 取消
```

预览页按钮：

```text
📤 确认发布到频道
🖼 换主图    🔄 重新生成
💬 侨联说
⬅️ 返回资料确认
```

### 正式发布硬门禁

必须按以下顺序：

```text
来源消息
→ canonical facts
→ review item
→ 批准事实
→ frozen publication package
→ Telegram 发送
→ receipt
→ publication instance
```

禁止：

- 绕开数据库直接用 Bot API 临时发送正式房源。
- 对发送结果未知的操作自动重试。
- 用服务 active 代替“频道帖子发布成功”。
- 用本地生成图片代替真实 Telegram 手机端验收。

### 发布失败恢复

后台区分三种状态：

- `发送前失败`：没有触达 Telegram，可以安全重试。
- `已发送待提交`：Telegram 已返回 receipt，只补写数据库，不能重发。
- `状态未知`：先查频道和 receipt，禁止盲目重试。

恢复按钮：

```text
🔄 安全重试
✅ 使用已保存 receipt 完成提交
⚠️ 返回恢复中心
```
